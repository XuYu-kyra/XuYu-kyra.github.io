        Reliability of ROS 2 Navigation under LiDAR FaultsLiDAR 故障下的 ROS 2 导航可靠性

        2026 MSc Robotics Dissertation机器人学硕士论文 Completed已完成

        A controlled fault-injection and evaluation framework for tracing how LiDAR degradation propagates through ROS 2 Nav2—from sensing and costmaps to planning, control, robot motion, and mission outcome.构建受控故障注入与评估框架，追踪 LiDAR 数据退化如何通过 ROS 2 Nav2 从感知与代价地图传播至规划、控制、机器人运动和最终任务结果。

        Problem研究问题

        A navigation task can still report success while becoming slower, less stable, or more dependent on replanning. Success rate alone can hide meaningful reliability loss.导航任务即使最终成功，也可能变慢、变得不稳定或更加依赖重规划；仅观察成功率会掩盖重要的可靠性损失。

        Method研究方法

        1. Injected configurable frontal LiDAR masking and intermittent sector dropout.
        2. Randomised baseline/fault order within matched runs in the same BARN world.
        3. Observed scan behaviour, costmaps, planner/controller activity, velocity commands, motion, and mission outcome.
        4. Used world-cluster bootstrap intervals, timeout-aware sensitivity analysis, and hierarchical Bayesian modelling.
        1. 注入可配置的正面 LiDAR 遮挡和间歇扇区数据丢失。
        2. 在同一 BARN 环境内匹配 baseline 与 fault，并随机化成对运行顺序。
        3. 观测扫描数据、代价地图、规划/控制活动、速度指令、机器人运动和任务结果。
        4. 采用按环境聚类的 bootstrap 区间、超时敏感性分析和分层 Bayesian 建模。
